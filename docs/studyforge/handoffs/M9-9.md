## 1. Content fixes

Every fix is in the lesson source. None needed a code change.

| lesson | file | fix | why |
|---|---|---|---|
| 2.3.1 | `08-object-oriented/README_2.3.1.md` | The key point now says `super()` must be first **up to Java 24**, and so at the course's Java 21 level. Java 25 relaxes this with flexible constructor bodies (JEP 513, a preview in Java 22-24).
