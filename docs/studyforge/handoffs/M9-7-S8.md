## How this office worked

This office took over from the previous S8 office, which was cut off by a usage limit. Its drafts were inventoried and each one was checked with the tools before it was trusted.

Under the user's ruling, one agent did all of the practice work:
- drafting;
- proofs;
- the adversary pass: subtle wrong solutions, written per practice.

The only other agents were the three quiz readers, one per role.

- **Shape.** Each practice is a CodeSignal-style Java task with a statement, a starter, a reference, JUnit tests and a plant for every edge case. The page's own examples are kept.
- **Proof before the pass.** Every practice was proved in the runner:
  - the reference ran 2 times, or 10 times for the 4 concurrent practices;
  - the starter ran once;
  - each plant ran once, or 10 times when concurrent.
- **Adversary pass.** 642 wrong solutions were written by hand across the 145 practices, each a single subtle change.
  - Every survivor that violated its statement led to a stronger test or a sharper statement. The practice was then proved again, and the survivor re-run until it was KILLED.
  - Survivors that do not violate their statement were discarded, with the reason recorded. Examples:
    - `Statement.close()` closes its `ResultSet` by the JDBC contract;
    - `relative()` in place of `absolute()`;
    - an extra `category == this` short-cut that is equivalent.
- **Identity rule.** Wherever a practice teaches equality, copying or immutability, the test objects are built at run time, and an identity or aliasing wrong solution ships and fails.
- **Concurrency.** Each concurrent practice is deterministic:
  - it uses latches, barriers or forced interleavings;
  - `38/unit-02 concurrent-subject` uses `ThreadMXBean.getLockOwnerId` to see that one thread is blocked on another's lock.

  Each wrong solution failed in 10 of 10 runs.
- **Quizzes.** Each quiz has 1 or 2 questions, set with `Page.quiz`. Every reading was taken by a reader agent other than the author:
  - Q1 read the page;
  - Q2 read only the stem and options, under `Q2_PROMPT` verbatim;
  - Q3 read the page, for every wrong option.

  On the final wording, all 62 questions hold Q1, Q2 and Q3, and Q3 ruled out all 124 wrong options.
