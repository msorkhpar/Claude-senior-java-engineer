## How the practices were made

- **Practice shape.** Each practice is a LeetCode/CodeSignal-style Java task. The reader gets:
  - a statement with worked examples;
  - a starter that compiles and throws `UnsupportedOperationException`;
  - JUnit 5 + AssertJ tests, one test method per case;
  - a workspace `pom.xml` that uses the course's own versions (JUnit 5.10.2, AssertJ 3.26.0, compiler 3.11.0, surefire 3.2.5) and pins Byte Buddy 1.17.5 the way the course does.
- **Commands.** Run is `mvn -o -q -f <workspace>/pom.xml compile`. Submit is `mvn -o -q -f <workspace>/pom.xml test`, and the report is read from `target/surefire-reports`.
- **Cases.** Each practice has one main case, the ask. Its edge cases number 1 to 4, and each edge case has its own planted wrong solution. A plant is a plausible mistake that still passes the ask: `==` on `Integer`, `index % size`, an `int` accumulator, a missing `Math.abs` trap, `&` for `&&`, `(Long) obj`, and so on.
- **Reuse, and what is never handed over.**
  - The course's own implementation is the reference where it fits. `BoxedSum.sum` is `WrapperVsPrimitive.sumWrapperArray`, and `Directory.cityOf` follows `getPersonName`.
  - The course's tests are the basis for the cases.
  - No practice hands the reader the answer in the starter. The worked solution sits behind the framework's closed "Show a worked solution" disclosure (see Q4).
- **Authorship.** The pass was driven by a scripted author, the way the skill describes. The drafts and the driver are in scratch and are not committed: `run_pass.py`, `drafts_u1.py` to `drafts_u4.py` and `common.py`. Everything they produced is in the bundles.
- **Proof before the real pass.** The whole pass was first run in a scratch clone of this branch. All 23 practices cleared on the first attempt there, so nothing in the worktree was ever deleted or rewritten. The worktree pass then re-ran every gate live, and those readings are below.
- **Order.** The plan numbers exercises by sorted name. Names carry a `pNN-` prefix so the practices appear in teaching order (F6).
