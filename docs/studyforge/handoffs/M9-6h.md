## Findings

None. The M9-6g finding, where an example panel named the editor when only the runner was down, is fixed by W505 and was read live above.

**A note on scope, not a finding.** The preflight reads `instance.env` from the corpus it mounts. A value handed to compose some other way (a second `--env-file`, or a shell variable) is not what it checks. In that case compose started the editor and runner, and only the site failed, on a port clash. `EXECUTION.md` names `instance.env` as the one place a port is set, so this is the contract and not a defect.
