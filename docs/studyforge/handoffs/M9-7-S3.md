## How the quizzes were judged

I judged none of the questions, and neither did the agents who wrote them. Separate agents read them, and none saw another's answers:

- **Q1:** two agents per batch, each given the pages and the questions without their keys.
- **Q2:** one agent per batch, given `Q2_PROMPT` word for word plus each stem and its options, never a page. Its answer was turned into the judgement by `page_free`.
- **Q3:** one agent per batch, given the pages and the keyed questions.

The rounds:

- **Round 1** read all 47 questions in three batches, using 12 reader agents. It refused 15:
  - Q2 on 7 of them, for a stem echo, the only specific option, or the only option without an absolute term;
  - Q3 on 8 of them, for a distractor the page does not rule out.
- **Rewording.** The authors reworded each refused question from the refusal's own sentence, keeping its id and the meaning of its key.
- **Round 2** read the 16 reworded questions, using 4 new reader agents. All held except `11-try-catch/unit-04/q-java9`, whose new option (c) the page still did not rule out.
- **q-java9 dropped.** The page's "Java 9+ Enhancements" is one sentence and one example, so two rounds found no distractor it rules out. The question was removed. Its aspect, `effectively-final`, now carries a written reason, and 3.1.4's quiz asks one question.
